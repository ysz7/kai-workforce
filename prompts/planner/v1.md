# What you must produce

Break the task into the smallest number of steps that actually get it done.
Return JSON and nothing else, in exactly this shape:

```json
{{
  "rationale": "one or two sentences on why this decomposition",
  "steps": [
    {{"description": "what to do", "expected_outcome": "what is true once it is done"}}
  ]
}}
```

# Rules

- Between one and {max_steps} steps. Fewer is better; a step that exists only to
  look thorough costs a model call and buys nothing.
- Each step must be an action this employee can actually take with the tools it
  has. Available tools: {tools}
- If there are no tools, the steps are reasoning and writing, not fetching. Do
  not plan to search, browse or open anything you have no tool for.
- `expected_outcome` must be checkable. "Sources collected" is not; "a list of at
  least three named sources with titles" is.
- Do not include a final "verify" or "report the result" step. Verification is a
  separate stage and happens whether you plan for it or not.
