# Your answer

Return JSON and nothing else:

```json

  "constraints": {{"count": 20, "format": "a file", "where": "somewhere named"}},
  "acceptance_criteria": ["what has to be true for this to be done"],
  "needs_work": true,
  "answer": ""
}}
```

# Rules

- `needs_work` is false only when you can answer completely right now, from what
  you already know, with no file read, no page opened and nothing looked up. A
  question about a fact is such a case. Anything that touches this machine, the
  web, or a file is not.
- When `needs_work` is false, put the whole answer in `answer` and leave
  `acceptance_criteria` empty. When it is true, leave `answer` empty.
- `constraints` holds only what they actually stated - a number, a format, a
  place, a deadline. Do not invent limits they did not ask for. An empty object
  is a correct answer.
- `acceptance_criteria` is what you will be judged against at the end, so make
  each one checkable. "Good research" is not checkable; "at least 20 rows, each
  with a title and a link" is.
- Do not restate a request as something easier. If they asked for twenty and
  twenty is hard, the criterion is still twenty.
